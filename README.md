## 📖 نبذة عن المشروع | About the Project

<div dir="rtl">

**Fashion Store** هو موقع متجر أزياء إلكتروني متكامل ومتجاوب، بيوفر تجربة تسوق سلسة وعصرية. الموقع بيسمح للمستخدمين بتصفح التصنيفات المختلفة، استعراض المنتجات المميزة، إضافة المنتجات لسلة التسوق، والاشتراك في النشرة البريدية — كل ده بتصميم أنيق وسريع.

</div>

**Fashion Store** is a fully responsive e-commerce fashion website that delivers a smooth, modern shopping experience. Users can browse categories, view featured products, add items to the cart, and subscribe to the newsletter — all wrapped in a clean, fast, and elegant design.

| 6 | ⭐ **تقييم المنتجات** | نظام نجوم لكل منتج |
