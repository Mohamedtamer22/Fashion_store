## 📖 نبذة عن المشروع | About

**بالعربي:**
موقع متجر أزياء إلكتروني متكامل ومتجاوب، يتيح للمستخدمين تصفح التصنيفات المختلفة، استعراض المنتجات المميزة، وإضافتها إلى سلة التسوق. مبني باستخدام HTML وCSS وJavaScript بشكل نظيف ومنظم.

**English:**
A fully responsive e-commerce fashion store website that allows users to browse categories, view featured products, and add them to the shopping cart. Built with clean, organized HTML, CSS, and JavaScript.
